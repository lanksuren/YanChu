# 言出 · 产品定义

> 一句话：**说话，就地写成书面文字。**

---

## 一、它是什么

一个常驻桌面的语音输入工具。按住键说话，文字直接出现在你正在打字的那个输入框里，中英文混说都行。

和语音输入法的区别：**它交付的是"整理好的文字"，不是"逐字转写"**。你说的是口语，落到屏幕上是书面语——口头语被清掉、标点补齐、语序通顺，但你说的事一点不走样。

---

## 二、核心能力

### 1. 一键说话，说完即得
两种方式，随场景选：
- **按住说话**：按住触发键说，松手出字；
- **按一下开始 / 停止**：按一下开始录音，再按一下或按 Esc 结束，适合长段口述。

触发键可以在设置里直接按出来（组合键、单个功能键或长按触发），不用改配置文件。
全程不需要切换窗口、不需要点按钮。
文字进入你按下说话键时正在编辑的那个输入框；说的过程中切了窗口，不影响落点——
如果原来的输入框已经失去焦点，文字会自动进入剪贴板，按 Ctrl+V 粘贴即可。

### 2. 中英文混说
一句话里中英文自由切换，不需要事先选语言、不需要手动切模式。
英文术语、人名、产品名、代码词保持原样，不被译成中文谐音。

### 3. 实时预览气泡
说话时，光标附近浮出一个气泡，边说边显示出正在识别的内容。
气泡只是"看"，不能编辑；它显示什么，最终就落什么。

### 4. 两级润色
- **小润色（句级、实时）**：每句话说完就改。去口头语、补标点、修同音错字、口语词换书面词。你在气泡里实时看到它变干净。
- **大润色（段级、段末）**：一段说完，整体再通顺一遍，统一语气和标点，让整段读起来像写出来的，不像说出来的。

分工清楚：**小的管措辞，大的管通顺，两者都不碰内容。**

### 5. 长口述自动分段
说话过程中有较长停顿时，自动把前面那段提前处理、提前落字，不用等你说完全部。
说十分钟，也是每段等一两秒，而不是最后等二十秒。

### 6. 鼠标旁的状态指示
鼠标边上一个极小的圆点，始终跟着，不挡操作。
**没说话时完全静止**，有声音时随音量起伏，处理后显示进度，落字后短暂确认。
作用只有一个：让你随时知道它开着、它在听、它听对了。

### 7. 词典与热词
可手动维护一份词表：人名、公司名、产品名、专业术语、缩写。
这些词优先被正确识别、且在润色时不被改写。支持导入导出。

### 8. 模型可替换
语音模型和润色模型都可替换、可切换；控制面板「模型」页可以直接选本地识别模型，
也可以保存多套本地 Ollama / OpenAI 兼容 API 的润色配置，点「使用」立即生效。
给用户的不是一堆模型名，而是**几档取向**（更快 / 更准 / 更强），背后绑不同模型；高级用户可指定具体模型。

### 9. 输入历史
每一次落字都留有记录，可回看、可复制、可删除，也可一键清空。
支持"刚才那句没落好，从历史里再拿一次"。

### 10. 全局可用
浏览器、微信、Word、IDE、终端、AI 对话窗口——凡是能打字的地方都能用。
不针对具体应用做特殊适配，保持行为一致。

---

## 三、形态与阶段

- **当前形态**：本地桌面应用（Windows 优先，跨平台）
- **未来形态**：作为 DeepSeek 生态下的插件存在，能力不变、外壳不同

产品内核只做一件事：**一段音频进去，一段成品文字出来。** 桌面应用和插件都是它的外壳，换壳不改内核。
